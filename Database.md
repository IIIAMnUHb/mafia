# База данных

mafia - Название базы данных
└ events - Все активные мафии
└ servers - Все сервера мафии
└ votes - Все голосования за кик

## Струткура
Требуется создать отдельные обьекты ТОЛЬКО в коллекции servers. Остальные генерируются сами.
Server {
    _id: "GUILD_ID сервера мафии",
    name: "Название сервера [Можно не настоящее]",
    status: "notallocated",
    roles: [
        "ROLE_ID ведущего",
        "ROLE_ID дона",
        "ROLE_ID мафии",
    ]
}
